# 🎨 Drawing App

A simple and smooth drawing app built with Flutter. Create sketches using multiple colors, adjustable brush sizes, and glow effects.

## ✨ Features

- Smooth drawing canvas
- Multiple brush colors
- Adjustable brush sizes
- Glow effect
- Clear canvas
